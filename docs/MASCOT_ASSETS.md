# Ilustrasi maskot website

Dibuat dengan built-in image_gen, 20 November 2026. Referensi karakter: `notaku/assets/notaku-warung.webp`. Hasil dipakai sebagai ilustrasi dekoratif di dekat penjelasan fitur; bukan screenshot aplikasi.

Format web: WebP 648 x 432 dengan alpha, lazy loading, dan dimensi tetap untuk menjaga tata letak. Ilustrasi asli disimpan oleh image_gen; berkas final berada di direktori assets masing-masing website.
