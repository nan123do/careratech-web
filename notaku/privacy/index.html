Kebijakan Privasi Notaku

Terakhir diperbarui: 28 September 2026

Kebijakan ini menjelaskan bagaimana aplikasi Notaku mengakses, menggunakan, menyimpan, dan melindungi data ketika Anda menggunakan aplikasi.

1. Data usaha di perangkat

Data transaksi, produk, pelanggan, pemasok, stok, kas, pengaturan, dan data usaha lain yang Anda masukkan disimpan secara lokal pada perangkat Anda. Notaku tidak mengunggah data tersebut ke server pengembang secara otomatis.

2. Backup Lokal

Jika Anda menggunakan Backup Lokal, file backup disimpan pada lokasi yang Anda pilih di perangkat. Anda bertanggung jawab menjaga akses dan salinan file tersebut.

3. Backup Google Drive

Google Drive adalah fitur opsional. Ketika Anda menghubungkannya, Notaku menggunakan autentikasi Google dan meminta akses ke folder data aplikasi (app data) untuk membuat, menampilkan, mengunduh, dan memulihkan file backup Notaku.

  • Notaku tidak meminta akses untuk membaca seluruh isi Google Drive Anda.
  • Notaku tidak menjual atau menggunakan data Google Anda untuk iklan.
  • File backup menggunakan kapasitas penyimpanan akun Google Anda.
  • Data hanya digunakan untuk menyediakan fungsi backup dan restore yang Anda minta.

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

4. Informasi akun Google

Saat Anda menghubungkan Google Drive, aplikasi dapat menampilkan identitas dasar akun yang diberikan Google, seperti alamat email, agar Anda mengetahui akun yang sedang terhubung. Informasi tersebut tidak dijual kepada pihak lain.

5. Izin perangkat

Beberapa fitur dapat meminta izin perangkat, misalnya akses dokumen untuk memilih lokasi backup, kamera untuk pemindaian, atau Bluetooth dan perangkat terdekat untuk printer. Izin digunakan hanya saat dibutuhkan oleh fitur terkait dan dapat dikelola melalui pengaturan Android.

6. Penyimpanan dan penghapusan

Data lokal tetap berada di perangkat sampai Anda menghapusnya, mereset aplikasi, atau menghapus aplikasi. File backup Google Drive tetap berada pada akun Google Anda sampai dihapus melalui Notaku atau pengaturan aplikasi terhubung di Google Drive. Memutuskan akun tidak selalu menghapus file backup yang sudah dibuat.

7. Keamanan dan tanggung jawab pengguna

Kami menerapkan langkah yang wajar untuk membatasi akses sesuai fungsi aplikasi. Namun, tidak ada metode penyimpanan yang sepenuhnya bebas risiko. Lindungi perangkat, akun Google, PIN, dan file backup Anda.

8. Perubahan kebijakan

Kebijakan ini dapat diperbarui ketika fitur atau kewajiban hukum berubah. Tanggal pembaruan terbaru akan dicantumkan pada halaman ini.
